# Briefing Markdown Contract

`news_briefing.md`는 v2 workflow의 단일 작업 원본이다. Codex가 검색, 원문 검증, 한국어 요약, 대표 기사 선정, 심층 리서치 결과를 이 파일 하나에 정리한다. HTML과 PDF 슬라이드는 이 파일에서만 생성한다.

## 파일 위치

```text
<run_dir>/_work/news_briefing.md
```

최종 산출물로 남기지 않는다.

## 작성 규칙

- `요약`은 HTML에 그대로 표시되므로 항상 자연스러운 한국어 문장으로 쓴다.
- 해외 기사는 `원제목`과 `번역제목`을 함께 둔다. HTML은 번역 제목을 우선 사용한다.
- `적용분야`는 의료 AI, 응급의료 AI, 응급실 AI, 중환자실 AI, 의료기기 AI, 의료영상 AI처럼 기사 맥락을 드러내는 값으로 둔다.
- 내부 점수, 후보 순위, scoring rule, rubric은 쓰지 않는다.
- 슬라이드 섹션은 Pencil 템플릿의 `bind.*` 자리값으로 들어가므로 각 항목을 짧고 독립적인 문장으로 작성한다.
- 확인되지 않은 정보는 슬라이드 문안에 넣지 말고, Codex 내부 검토에서만 보류한다.
- 번호가 붙은 항목은 템플릿이 받을 수 있는 최대 개수다. 조사에서 확인된 만큼만 작성하고, 근거가 없는 항목은 비워 둔다.
- 반복 항목을 모두 채우기 위해 사실을 늘리거나 일반론을 넣지 않는다.
