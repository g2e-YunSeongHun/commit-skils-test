# Slide Prompt

이 파일은 NotebookLM `slide-deck` 초안 생성과 `revise-slide` 보정에 쓰는 기준 프롬프트를 담는다.

<!--DECK_PROMPT_START-->
# Role: 의료 AI 뉴스 전문가 및 슬라이드 디자인 전문가
# Goal: Codex가 선정하고 심층 리서치한 대표 기사를 기반으로 비즈니스 프리젠테이션을 설계한다.

추가 컨텍스트:
- 주간 식별자: {{WEEK_ID}}
- 대표 기사 제목: {{FEATURED_TITLE}}
- 매체: {{FEATURED_MEDIA}}
- 날짜: {{FEATURED_DATE}}
- 관련 기관/회사: {{FEATURED_ORG}}
- 대표 기사 링크: {{FEATURED_LINK}}
- 소스 범위: {{SOURCE_SCOPE}}

내부 선정 점수, 점수표, 후보 순위, 후보 비교, rubric은 슬라이드에 넣지 않는다. 선정 과정은 슬라이드 주제가 아니며, 필요한 경우 "Codex가 선정한 대표 기사" 정도의 자연어 맥락만 사용한다.

< 디자인 가이드라인 >
- 배경색: #FFFFFF
- 텍스트 색상: 본문 #222222, 보조 설명 #555555
- 포인트 색상: Deep Blue 계열 강조색
- 구분선: 각 섹션과 헤더 사이에 #E6E6E6 색상의 1pt 실선 사용
- 텍스트 크기:
  - 제목: 32px, Bold
  - 본문: 18px
  - 부제목: 24px, Italic
- 도표와 이미지:
  - 관련 이미지나 도표가 있을 경우 슬라이드 크기의 40-50% 범위를 유지
  - 텍스트와 이미지의 비율은 50:50에 가깝게 유지

< 슬라이드 구성 및 텍스트 규칙 >
- 반드시 정확히 4장의 슬라이드를 만든다.
- 각 슬라이드는 간결하고 비즈니스 프리젠테이션 스타일로 작성한다.
- 모든 문구는 한국어로 작성한다.
- 새 대표 기사를 선정하거나 소스 밖 내용을 추정하지 않는다.
- 기사 원문, 공식자료, 제품 페이지, 논문, 규제·인허가 자료, Codex 심층 리서치에서 확인된 사실만 본문 팩트로 쓴다.
- 추론이나 전망은 "시사점", "불확실한 지점", "추적할 신호"로 분리한다.
- 확인되지 않은 회사 이력, 성능 수치, 도입 병원, 규제 상태를 만들어내지 않는다.
- Codex가 제공한 대표 기사 원문, 공개용 선정 배경, 심층 리서치 내용을 중심으로 구성한다.
- 각 슬라이드는 Codex 심층 리서치의 같은 이름 섹션을 우선 사용한다. 슬라이드 1은 `이번 주 핵심 팩트`, 슬라이드 2는 `AI 기술 설명`, 슬라이드 3은 `회사·기관 팩트시트`, 슬라이드 4는 `이번 주 인사이트`를 기준으로 작성한다.

### 슬라이드 1: 이번 주 핵심 팩트
- 제목: 대표 기사 제목
- 누가, 언제, 무엇을 발표·도입·제휴했는지 확인된 사실만 정리
- 핵심 팩트 3개를 bullet point로 정리
- 발표/도입/제휴 관계를 보여주는 간단한 표 또는 관계도 구성

### 슬라이드 2: AI 기술 설명
- 기사에서 다루는 AI 또는 의료·응급·중환자의료 기술 이름과 설명
- 해결하려는 의료 문제
- 입력 데이터, AI가 하는 판단·자동화·보조, 출력 결과
- 의료 현장, 응급실, 중환자실 workflow에서 쓰이는 위치
- 기술 작동 흐름을 `입력 -> AI 처리 -> 현장 활용` 형태의 다이어그램으로 구성

### 슬라이드 3: 회사·기관 팩트시트
- 회사 또는 기관 이름과 기사에서 확인된 역할
- 기존 제품·역량·파트너·도입 사례 중 소스로 확인된 내용
- 이번 기사와 연결되는 사업 맥락
- 실제 도입, PoC, 제휴 발표, 허가, 논문, 검증 여부를 확인된 범위에서만 표시
- 확인되지 않은 항목은 "확인 필요" 또는 "소스에서 확인 안 됨"으로 구분

### 슬라이드 4: 이번 주 인사이트
- 의료기관, 응급실, 중환자실 workflow에 줄 수 있는 영향
- 산업적 의미와 현장 적용상 주의점
- 아직 불확실한 지점
- 다음에 추적할 신호 3개
- 핵심 인사이트를 강조 블록 또는 요약 표로 구성

대표 기사와 직접 관계된 회사나 기관이 불명확하면 기사에 등장하는 핵심 기관 또는 기술 주체를 중심으로 슬라이드 3을 구성한다.

슬라이드 1을 "이번 주 핵심 팩트" 슬라이드로 고정한다. 제목은 "{{FEATURED_TITLE}}" 중심으로 두고, 누가/언제/무엇을 발표·도입·제휴했는지 확인된 사실만 정리한다. 핵심 팩트 3개 bullet과 발표·도입·제휴 관계를 보여주는 표 또는 관계도를 넣고, 추론·전망·내부 선정 점수는 제외한다.
<!--SLIDE_1_REVISION_END-->

<!--SLIDE_2_REVISION_START-->
슬라이드 2를 "AI 기술 설명" 슬라이드로 고정한다. 기사에서 다룬 AI 또는 의료·응급·중환자의료 기술의 이름, 해결하려는 문제, 입력 데이터, AI 처리, 출력 결과, 현장 workflow 연결을 분명히 나눈다. 작동 흐름은 `입력 -> AI 처리 -> 현장 활용` 다이어그램으로 구성하고, 소스에서 확인되지 않은 성능 수치나 기능은 만들지 않는다.
<!--SLIDE_2_REVISION_END-->

<!--SLIDE_3_REVISION_START-->
슬라이드 3을 "회사·기관 팩트시트" 슬라이드로 고정한다. 관련 회사나 기관의 기사 내 역할, 기존 제품·역량·파트너·도입 사례, 이번 기사와 연결되는 사업 맥락, 도입·검증·허가·논문 상태를 확인된 사실 위주로 정리한다. 확인되지 않은 항목은 "확인 필요" 또는 "소스에서 확인 안 됨"으로 표시한다.
<!--SLIDE_3_REVISION_END-->

<!--SLIDE_4_REVISION_START-->
슬라이드 4를 "이번 주 인사이트" 슬라이드로 고정한다. 의료기관, 응급실, 중환자실 workflow에 줄 수 있는 영향, 산업적 의미, 현장 적용상 주의점, 아직 불확실한 지점, 다음에 추적할 신호 3개를 구분한다. 추론은 사실처럼 쓰지 말고 시사점으로 분리하며, 핵심 인사이트는 강조 블록 또는 요약 표로 구성한다.
